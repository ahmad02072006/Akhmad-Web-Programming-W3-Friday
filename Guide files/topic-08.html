08

CSS Animations & @keyframes

Q14

@keyframes defines a multi-step animation sequence: you name it, then describe the CSS properties at each percentage point from 0% (start) to 100% (end). You can add as many stops as needed. The animation property then attaches the sequence to an element.

The animation shorthand: name duration timing-function delay iteration-count direction fill-mode. The most important non-obvious value is fill-mode: forwards — without it the element snaps back to its initial state when the animation finishes. Use iteration-count: infinite for looping animations like loading spinners.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Fade + slide in */ @keyframes fadeSlideIn { from { opacity: 0; transform: translateY(30px); } to { opacity: 1; transform: translateY(0); } } /* Pulse */ @keyframes pulse { 0%, 100% { transform: scale(1); opacity: 1; } 50% { transform: scale(1.1); opacity: 0.7; } } /* Spinning loader */ @keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } .hero { animation: fadeSlideIn 0.8s ease-out forwards; font-size: 28px; font-weight: bold; color: #0f766e; padding: 20px; } .badge { display: inline-block; background: #0f766e; color: white; padding: 6px 16px; border-radius: 20px; animation: pulse 1.5s ease-in-out infinite; } .spinner { width: 40px; height: 40px; border: 4px solid #ccfbf1; border-top-color: #0f766e; border-radius: 50%; animation: spin 0.8s linear infinite; margin: 20px; } </style> </head> <body> <div class="hero">Hello! I faded and slid in on load.</div> <span class="badge">Live</span> <div class="spinner"></div> </body> </html>

Key Points

  • @keyframes name { from{} to{} } or 0%{} 25%{} 100%{}.
  • animation: name duration timing delay iterations direction fill-mode.
  • fill-mode: forwards keeps the final state — without it element snaps back.
  • iteration-count: infinite loops forever — perfect for spinners.
